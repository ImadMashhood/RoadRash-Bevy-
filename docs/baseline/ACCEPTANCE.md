# Release acceptance contract

Every result records build revision, platform, input corpus, scenario and command/manual procedure. A skipped scenario is not a pass.

| Gate | Required executable evidence | Current status |
| --- | --- | --- |
| G0 | Import supported ISO/directory, reject corrupted corpus, inspect all required assets | Not complete |
| G1 | One measured course, controlled driving replay, faithful timing and working 3D test section | Not complete |
| G2 | Full rider field, combat, crashes/recovery, traffic and police through all terminal outcomes | Not complete |
| G3 | Complete offline career, menus, economy, saves and required media | Not complete |
| G4 | One approved enhancement pilot, animation-family review, validated mod override/fallback | Not complete |
| G5 | Packaged clean-profile install and all supported content exercised on declared hardware | Not complete |

Release blockers: crash/panic on supported input, importer path escape or partial activation, lost/duplicated career transactions, stuck race/recovery flow, missing required content, undiagnosed simulation divergence in accepted scenarios, or shipped private game payload. A performance budget must be measured and agreed after G1; no invented FPS claim is accepted.

Coverage must include all five course files and five level selections (25 setup combinations), all 15 bike slots, eight character selections, win/loss/bust/wreck/quit, corrupt/interrupted saves, native/enhanced textures, and a clean profile without developer caches. Course/level selection availability and exact rules remain research questions, not assumed equivalent layouts.

Original-data tests are opt-in locally. Public CI uses original authored synthetic fixtures. Original audio, images, binaries and generated private art stay outside repository and distribution artifacts.
