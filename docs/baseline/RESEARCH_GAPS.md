# Static research and optional historical questions

Original-runtime comparisons were removed from completion requirements by the owner. See [scope decision](../SCOPE_CHANGES.md). A working original installation is not needed to continue or release this recreation.

Static inventories in executable/ preserve screen/popup records, raw bindings, selected actor IDs and source distance tables. Dynamic menu handlers, course traversal, combat timing and gameplay rules are implemented in their later phases using source research plus explicit intended behavior and tests.

Confidence remains explicit: verified-local, upstream-reported, inferred, or unknown. Unknown original behavior is not falsely reported as verified. Internal engine replays and screenshot baselines replace required original-runtime comparison.
