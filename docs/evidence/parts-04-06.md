## Implemented interfaces

- `rr-formats`: checked binary ranges/endian reads, resource directories/envelopes, CEL and mip textures, BOB frames including empty slots, indexed palettes/remaps, hash-gated PE table extraction, bounded compressed family traversal, RRI/JPEG and deterministic RGBA PNG export. Unknown fields and raw source masters remain inspectable.
- `rr-content`: schema-1 semantic IDs and typed references, provenance/dimensions/trim/pivot, content-addressed storage, independent overrides, dependency/recipe cache invalidation, source/blob verification, coverage report, searchable contact sheet and browser inspector.
- `rr-simulation`: typed units and stable actors, route/branch graph positions, tick-ordered commands, owned snapshots, explicit stage order, separate seeded RNG, integer arithmetic, canonical state/checkpoints, bounded schema-1 replay and GPU-free CLI.
- `rr-game`/`rr-presentation`: catalog-backed rider sprite selection, snapshot interpolation, ordered Bevy sets, native/override images, live texture switch and graphical replay reporting. A mutable Sprite query overlap found during graphical startup was corrected with disjoint query filters and a regression test.

## Exact verification commands

```sh
cargo test --locked -p rr-formats -p rr-simulation -p rr-import -p rr-content
cargo test --locked --release -p rr-presentation --target-dir ../target
cargo fmt --all --check
cargo clippy --locked --workspace --all-targets --target-dir ../target -- -D warnings

python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/check_workflow_guards.py
../target/release/rr-format-fuzz 10000 local/format-fuzz.json
../target/release/rr-content build local/game-install local/catalog
```

Results: **53 Rust tests passed** (formats 15, content 7, simulation 14, import 15, presentation 2), **10 Python tests passed**; formatting, workspace Clippy and linked release build passed. Negative workflow checks reject deliberately unformatted source and a stale lockfile. These local results do not claim a new remote Actions execution. The previous clean-container receipt applies only to its recorded earlier source hashes.

[Corpus coverage](corpus-04-06.json): **341/341 source records, 2,975 entries, 164 decoded sources, 177 explicitly retained opaque sources, zero conversion errors**. Retained sources include later audio/video/text subsystems and unknown layouts; accounting for them does not mean those subsystems are implemented. ## Headless and actual graphical replay

For each `RATE` in `30`, `60`, `144`, `irregular`:

```sh
../target/release/rr-replay docs/fixtures/replay.json RATE local/headless-RATE.json
../target/release/rr-game --catalog local/catalog --replay docs/fixtures/replay.json --render-hz RATE --report local/rendered-RATE.json --capture local/rendered-RATE.png
```

Then:

```sh
../target/release/rr-game --catalog local/catalog --replay docs/fixtures/replay.json --enhanced-image local/authored-override.png --switch-textures-at 60 --report local/rendered-switched.json
```

The authored override was generated by `rr-content`'s `authored_override` example. It is test art, not an AI-enhanced or approved asset. Reports were parsed and asserted equal between headless/GPU and across all schedules and the live switch at ticks 30, 60, 90 and 120. [Replay matrix](replay-matrix.json) records the actual values; final SHA-256 is `f70c202279f360fc89e95d503443a91a523c816788d9e62102a6d3572fc7f143`. Graphical startup selected the catalog rider and the switch log confirmed tick 60.

These are controlled **virtual presentation schedules**, not hardware FPS benchmarks. Separately, presentation-system tests compare sampled sprite positions: interpolation stays bounded, higher-rate steps are smaller, and the final position and gameplay hash agree. Owned snapshot mutation, command timing, held-input/replay equivalence, actor lifetime, split/merge routes, RNG isolation, arithmetic boundaries and canonical encoding have dedicated regressions.

## Compatibility and scope limits

Catalog/replay schema mismatches fail explicitly. Decoder fingerprints and converter versions invalidate stale cache; canonical-source renames need explicit logical-ID migration. Standard modern RGB JPEG decoding does not emulate the original quantizer. Bottom-center pivots and 60 Hz handling are declared authored policies. Unknown family/CEL/cloud semantics remain raw and labeled.

This completes foundational formats, tooling and simulation architecture. Source course reconstruction is Phase 07; original handling/animation/combat/AI, career, saves and audio/video playback remain later work. Declared stage extension slots do not implement those systems. Parts 01–06 completion is not a claim that the whole game is complete or that original runtime parity was measured. 3D remains deferred.
